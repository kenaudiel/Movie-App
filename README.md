## Introduction
This is one of my repository that records my learning progression related to React.js. Here, I'm building web-based movie app to implement React concepts that I have been learned. Not only react, I also use Tailwind CSS as CSS frameworks, shadcn/ui for ui components library, React Router for routing, and other stuff. The main point is to practicing my front-end skill that follows enterprise market demand by using real-project tools.

## Tech Stack
- React.js
- Tailwind CSS
- shadcn/ui
- React Router
